# Meus Gastos 💸

Controle de despesas rápido e simples para o celular. Funciona **sem internet** e seus dados ficam **só no seu aparelho**: sem cadastro, sem servidor.

👉 **Abrir o app:** https://ler0x1.github.io/meus-gastos/

## Como instalar (Android)
1. Abra o link acima **no Chrome** (não pelo navegador do WhatsApp/Instagram).
2. Toque em **Instalar** no cartão azul da tela inicial — ou menu ⋮ → **Instalar app**.
3. Pronto: o ícone *Meus Gastos* aparece com seus outros apps.

**iPhone (Safari):** botão Compartilhar → *Adicionar à Tela de Início*.

## O que ele faz
- Lançamento em segundos: digite `uber 23,50` e pronto
- Aprende suas descrições e sugere categoria, valor e forma de pagamento
- Colar vários gastos de uma vez
- Gastos fixos que entram sozinhos todo mês, com aviso de "a pagar" / "pago"
- Valor por dia (salário ÷ 30), orçamento mensal e relatórios
- Backup e exportação para planilha

## Privacidade
Tudo é salvo no armazenamento do navegador do seu celular. Nada é enviado para este repositório nem para nenhum servidor. Faça backups em *Ajustes → Fazer backup*.
