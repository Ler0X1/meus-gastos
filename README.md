# Meus Gastos

Controle de despesas rápido, que funciona offline e fica instalado no celular como aplicativo (PWA).

Os dados ficam salvos apenas no aparelho de quem usa — nada é enviado para este repositório.

**Instalar:** abra o endereço do GitHub Pages no celular → Android (Chrome): menu ⋮ → *Instalar app* · iPhone (Safari): Compartilhar → *Adicionar à Tela de Início*.
